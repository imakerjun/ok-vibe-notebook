# 📓 바이브 코딩 노트 템플릿

OK금융그룹 바이브 코딩 워크숍 참가자용 노트 템플릿입니다.

워크숍에서 스킬 1개와 웹앱 1개를 만들었습니다. 이 템플릿은 그 내용을 **내 사례로 정리하는 노트**입니다. 강의 문서와 같은 모양으로 나옵니다. 직접 쓰는 건 질문에 대한 답뿐이고, 페이지는 Claude가 채웁니다.

설치할 것은 없습니다. 워크숍에서 쓴 Claude 데스크톱 앱 Code 탭이면 됩니다.

## 들어 있는 것

| 파일 | 무엇 |
|---|---|
| `index.html` | 홈. 노트 한 줄 소개, 만든 것 2개, 다음 주 할 일 |
| `skill.html` | 1부. 내 업무 스킬 |
| `webapp.html` | 2부. 내 업무 웹앱 |
| `components.html` | 블록 모음. Claude가 보고 따라 쓰는 견본 |
| `assets/style.css` | 노션 톤 모양. 고치지 않습니다 |
| `images/` | 내 화면 캡처를 넣는 곳 |
| `.claude/skills/notebook/` | 페이지를 채우는 스킬 `/notebook` |

## 쓰는 순서 · 20분

### 1. 받기 (2분)

1. 이 페이지 위쪽 초록색 **Code** 버튼 → **Download ZIP**을 누릅니다.
2. 받은 ZIP 파일의 압축을 풉니다.
3. 풀린 폴더 이름을 `my-notebook`으로 바꾸고 **바탕화면**으로 옮깁니다. 워크숍 때 쓴 `ok-workshop` 폴더 옆입니다.

폴더를 열었을 때 `index.html`이 바로 보여야 맞습니다. Windows에서는 압축을 풀면 같은 이름 폴더가 한 겹 더 생기기도 합니다. 그럴 땐 `index.html`이 보이는 안쪽 폴더를 씁니다.

### 2. 새 환경 만들기 (2분)

워크숍 사전 미션에서 `ok-workshop` 환경을 만들었던 방법 그대로입니다.

Code 탭 **+ 새로 생성** → **환경 선택**(▾) → **+ 새 환경** → 이름 `my-notebook`, 폴더 `my-notebook` → **환경 만들기**.

> ⚠️ `ok-workshop` 환경에서 열면 `/notebook` 스킬이 안 보입니다. 스킬은 그 환경 폴더 안에 있는 것만 보입니다.

### 3. 채우기 (15분)

`my-notebook` 환경에서 새 작업을 열고 이렇게 보냅니다.

```text
/notebook 1부 페이지부터 채워줘
```

Claude가 먼저 바탕화면 `ok-workshop` 폴더에서 내 스킬과 웹앱을 읽습니다. 다른 폴더를 읽어서 **허용 창이 뜹니다.** 읽기만 하고 고치지 않습니다. 허용합니다.

재료에 없는 것만 하나씩 묻습니다. 매번 다시 설명하던 장면, 빗나간 곳, 다음 주 할 일 같은 것입니다. 짧게 답하면 됩니다. 모르면 "넘어가자"라고 하면 그 칸은 비워 둡니다.

1부가 끝나면 `2부 채워줘`, `홈 채워줘` 순서로 이어 갑니다.

### 4. 보기

`my-notebook` 폴더에서 `index.html`을 더블클릭합니다. 브라우저에 내 노트가 열립니다. 고칠 곳이 보이면 Claude에게 말로 시킵니다.

```text
skill.html의 "왜 만들었나"를 두 문장으로 줄여줘. 다른 곳은 바꾸지 마.
```

### 5. 주소로 올리기 (선택, 10분)

워크숍 2부에서 웹앱을 올린 방법과 같습니다.

> 🔒 **올리기 전에 한 번 더 봅니다.** 주소를 아는 누구나 읽습니다. `/notebook 공개 점검해줘`를 보내 점검표가 전부 통과인지 확인합니다. 고객정보, 동료 실명, 회사 숫자가 하나라도 있으면 올리지 않습니다.

1. GitHub에서 새 저장소 `my-notebook`을 만듭니다.
2. **Add file** → **Upload files**. `my-notebook` 폴더 **안의** 파일과 폴더(`assets`, `images` 포함)를 전부 끌어다 놓습니다. 폴더째 올리면 주소가 안 맞습니다.
3. Vercel 대시보드 → **Add New…** → **Project** → `my-notebook` 옆 **Import** → **Deploy**.

## 그림 넣기

강의 문서의 일러스트는 이 템플릿에 들어 있지 않습니다. 그림 사이트마다 약관이 있고, 그림 파일을 묶어 다시 나눠 주는 것을 막는 곳이 많아서입니다.

넣고 싶으면 그림을 직접 받아 `images/` 폴더에 넣고 Claude에게 "images/파일이름.png를 OO 아래 넣어줘"라고 합니다. 받은 사이트의 약관은 각자 확인합니다.

## 막혔을 때

| 상황 | 해볼 것 |
|---|---|
| `/`를 쳐도 `notebook`이 목록에 없다 | 환경이 `my-notebook`인지 봅니다. 폴더 안에 `index.html`이 바로 있는지도 봅니다 |
| `ok-workshop` 폴더를 못 찾는다고 한다 | 폴더 위치를 알려 줍니다. 예: "바탕화면/ok-workshop에 있어" |
| 페이지 모양이 깨졌다 | `assets` 폴더가 `index.html`과 같은 곳에 있는지 봅니다 |
| 글씨체가 다르게 보인다 | 회사망이 글꼴 사이트를 막은 경우입니다. 기본 글꼴로 보입니다. 내용에는 문제없습니다 |
| 올린 주소가 404다 | GitHub 저장소 맨 위에 `index.html`이 있는지 봅니다 |
